# 杭州麻将

## 杭州麻将入门教学（新手向，共5节，偏简略） ^c7e3e932-abb3-ccc5
- 一、基本规则与概念
	- 用牌情况：136张，无8张花牌，7张字牌统称风牌（含国标中的三元牌/箭牌）
	- 开牌与位置：未详细说明，仅提及需了解确定方法
	- 吃碰杠规则
		- 允许吃碰杠，杠分暗杠、明杠、加杠三种
		- 区别于上海敲麻：无“不允许漏碰吃”规则，吃一般无意义（仅特殊规则局存在）
		- 特殊限制：一家打白板后，另三家仅能杠（加杠）、抓打或胡牌，不可吃碰明杠
	- 民间差异：线下多自定规则，标准规则为“三摊承包规则”
- 二、胡牌番型与倍数
	- 平胡（自摸）：最常见，手牌为1对将牌+4副成牌（吃碰杠也算成牌），例：摸5万后形成345条、678条、567万等成牌+白板，2/4万成刻子定将
	- 爆头（敲响）：剩成牌+白板（无将牌），下一巡摸任意牌胡，即单调白板，例：234筒、345筒、567万成牌+白板，摸任意牌胡
	- 杠开：开杠后摸牌胡，例：杠9万后摸3/6筒
	- 财漂：打财神后，下一巡摸任意牌胡
	- 七对：14张手牌为7对，含4张相同牌则为豪华七对
	- 组合番型：杠爆（开杠后摸任意牌胡）、七对子爆头（摸任意牌为七对）、杠漂（开杠打财神后摸任意牌胡）、十风胡牌（未详说）
- 三、听牌类型（胡牌前一阶段，按听口从少到多）
	- 对倒胡：手牌2对，需抓相同牌使1对成刻子胡，难胡易改良，例：摸3万打2万改听14万
	- 单钓：无对子，等凑对胡，可改听，例：仅摸3条组队胡；摸白板打3条下轮爆头；摸7万打3条改听47万
	- 边张/卡张：仅胡1门，可改良，例：卡4条，摸6条打3条改听47条
	- 双面听（最常见）：例1：摸4/7条平胡；例2：缺将但4连牌型，摸2/5万组对胡
	- 三面听：多见于长连牌型、刻子带单牌型（未详说）
	- 多面听：杭州麻将少见，后续解说听口查看方法
	- 含白板的特殊听牌
		- 四大叫：白板为万能牌，摸任意牌胡（听4门），白板与搭子组成成牌
		- 荡张：有成牌+将牌，剩白板挂单张，摸任意关联单牌胡；碰对子打单张可爆头
		- 特殊多门听：例：3条当张胡12345条，6条当张胡45678条，共胡8门；吃碰1摊可打成爆头
- 四、听口计算相关
	- 易错题：含关联对子（如4筒、6筒）+白板，不可简单归为对倒胡，白板可当同色牌（如456筒成牌，剩46筒搭子）
	- 疑难牌型：常见于清一色，杭州麻将罕见，血流麻将多见
	- 计算方法
		- 假定将牌法：依次假定某牌为将牌，判断剩余牌能否组成成牌，例：3万定将剩牌不成成牌则不可，2万定将剩牌成成牌则抓2万胡；23万不定将则抽234万顺子后分析
		- 传递性原理：如678万顺子，摸6万胡则摸9万也胡（789万顺子），摸6万与某情况等价
		- 两头抽离成牌法：适用于部分案例分析
	- 白板财神与爆头：上述案例抓白板财神均能爆头

## 杭州麻将基本常识
- 麻将基本常识
	- 牌具特性
		- 对称性
		- 关联性：序数牌关联张可组成搭子
	- 核心原理
		- **筋线牌原理：147、258、369（从中间向边缘延伸）以此向下家打安全牌，重要且需掌握**
		- *封闭性原理：由关联性推导，被封闭牌无关联性、难成顺子，适合七对/单钓听口*
	- 关键概念
		- 金三银七：序数牌中3、7为关键张，不轻易打
		- 生张&熟张：常用概念，需了解含义
		- **序数对子碰牌几率：风张＞19＞28＞456＞37，序数牌叠加易打出，碰出概率最高**
- 听口选择原则
	- **核心原则：张数多原则、封闭原则、半封闭原则，前三条较重要，必须了解**
	- 生熟张原则：点炮麻将（如四川麻将）听口选择关键，自摸麻将中相对不重要
- 基本牌型及性质
	- 基础搭子
		- 边张搭子：抓1门牌成牌，改良成双面搭需2步
		- 卡张搭子：抓1门牌成牌，可两端改良
		- **边卡搭子：含2、8的卡张搭子，抓1门牌成牌，仅一端改良（与1、3、7、9边卡性质一致）**
		- 双面搭子：最受欢迎，可两端成牌
		- 搭子价值评价维度：成牌难度、改良难度（如68条与79条边卡搭子改良难度一致）
		- **搭子价值：双面搭＞卡张＞边卡搭＞边搭**
	- 四张牌组成的牌型
		- 3456万（四连牌型）：进6门牌可组搭，进2门牌可组对，优质牌型
		- 3445万（大肚牌型）：摸相关牌易成双面搭，组队能力弱（仅进中间4万凑对，最多2张）
		- 3345万（边肚牌型）：可两头组队，组搭能力弱（仅进2、4万成牌/双面搭，进1、5万为卡张搭子）
		- 衍牌：组队能力强（可两头组队、变四连牌型两端双面钓），需认识其性质优势
		- **组搭能力：四连＞大肚＞边肚＞衍牌**
		- **组对能力：衍牌＞四连≈边肚＞大肚**
	- 补充牌型
		- 三连坎&四连坎：牌局后期四连坎可拆为三连坎
		- **刻子带单牌型：优势是可做三面听，有对子时可打掉单张留刻子**
	- 麻将口诀（牌型相关）
		- 无将打大肚，有将拆边肚
		- 缺搭缺对，留四连
		- 打短留长：打掉孤张，留衍牌凑对子
- 做大牌策略（有局求大）
	- 常见做大牌场景
		- 能胡不胡等做大：爆头不走
			- 例1：摸2、5万不舍自摸，四门牌进张可变爆头，后续还能等飘财
			- 例2：有刚爆机会（仅2张牌），最多等1-2圈，避免截胡风险
			- 例3：多门进张可做大牌，值得等待
		- 七对子爆头不走：例4，摸6条打白板，做七对子漂
		- 荡张不胡牌：例5，三门牌可做爆头，需承担后续不上牌、小胡也胡不了的风险
	- 特殊做大牌情况
		- 牌型二选一：可做杠爆或豪七，需观察1、4万等牌张余量
		- 做十风：有机会则开局搏，拦截十风有小技巧

## 麻将拆搭核心知识 ^c472df48-01e9-1b9c
- 一、听牌前关键阶段概念
	- 听牌：胡牌前的形态
	- 一进听：打1张+摸有用牌+再打1张可听牌
		- 普通案例：打八筒→摸3万→打5万听边七筒
		- 特殊案例（双操）：五对（七对子一进听）、财神+对子=五（七对子+平和一进听，可保双方向）
	- 二进听：与一进听逻辑类似，需两次操作达听牌
- 二、拆搭核心原则（一进听为主）
	- 四搭凑搭原则
		- **核心：手牌4搭需靠搭，有一对时留靠搭强牌，打靠搭弱边度牌**
		- 案例1（有对子）：打四条vs打六筒，打四条进张少1门但听口质量高（多双面听）
		- 案例2（缺对子）：打组对弱大肚牌（六筒），有效进张最多且听口不弱
		- 特殊牌型：一对三单牌型（用叙述牌关联性原理，留关联强单张，如打二筒）、二八序数牌（留关联张无重合的，如留八条打二筒）
	- 六搭拆搭原则
		- **核心：胡牌需5搭，拆价值最低边卡搭子**
		- 特殊情况：双面搭**重复进张**（如34/67万），打4万不丢25万进张，拆其他单张（八筒/7万）会丢张
	- 三对拆对原则
		- 案例1：拆七条对子，保双面搭，遇6/8筒可拆12万搭子（留七筒改良）
		- 案例2（一进听）：推演各打法进张+听口质量，掌握分析思路
	- 四人抬轿牌型原则
		- **结论：留两个双面搭凑对/组牌**
		- 验证：打7万，摸任意筒子可听牌（如摸一筒→打三筒听6/9筒）
	- 两对牌型原则
		- **核心：不拆对成两对半，保最多有效进张+碰牌机会**
		- 误区：着急拆对会失碰牌机会+减少进张
	- **缺对牌型原则：打短流长，保连续序数牌（易组队）**
- 三、有财神时的拆搭要点
	- 特点：无绝对标准答案，需灵活判断
	- 案例1：打红中胡牌概率高，拆45条/45万搭子有爆头机会
	- 案例2：有白板可不用遵守“一对定将”原则（如打6万易胡牌）
	- 案例3：四人抬轿→六人抬轿，碰6万（虽仍一进听，但进张增多+保爆头机会）
	- 案例4：进张一致看改良能力（如打5万vs6万，摸7筒时打5万可听9门，打6万仅听7门）
- 四、学习方法
	- 核心：类似数学，需多刷题
	- 重点：掌握进张数+听口质量的分析思路

## 麻将牌效理论
- 牌效理论基本含义
	- 拆搭原理符合牌效理论选择
- 牌效理论三大原则
	- **原则一：开局少吃碰**
		- 核心逻辑：手牌散乱时摸有效牌概率高，手牌整齐后摸牌边际收益递减
		- 示例：上家打出一条不建议吃
	- **原则二：147打1，258打5，369打9**
		- 1万和4万存在23万的重复进张，打1万只丢1万本身的进张
	- 原则三：优化牌型以提升进张概率
		- 1224牌型，需摸2张三才能成牌，难度大，拆掉1保留224
		- 1334牌型，是123一副成牌带34的双面搭，视其他搭子情况决定
- 杭州麻将杠牌特殊规则（结合牌效）
	- 常规操作：手中有杠牌，一般留到听牌后开杠
	- 特殊情况：需增加牌效时可提前开杠（参考具体说明）
	- 示例：保留二条有效进张最多5门牌，提前开杠则有10门牌听牌机会
- 听口选择常用技巧
	- **1、七对子、单钓首选牌池现过1张的风牌和幺九牌，以及被封闭的序数牌。**
	- 2、**杭州麻将“戒剩单骑”**：尽量不要把手牌打成只剩一张牌去听单钓（非白板）。单钓本就不易和牌，还失去了改良多面听的 机会。特别是庄家上家位置！
	- 3、**宁听卡张，不听对倒**：卡张和对倒进牌数相同，但对倒胡更难上牌。因为每一对外面一共就2张牌，有可能被别人带住，或在牌墙后20张，或和别人对子撞车，永远摸不到。卡张一门牌有 四张，即使被人带住1-2张，也还有机会。
	- 4、**根据牌池灵活选择听口**。例如，7条被碰断，356条的手牌可 以直接打掉6条去听卡4条，如果摸进2条还能改良成双面听。又例如，手上有33万+67条，直至牌局中后期牌池里一张8条未现， 那么很可能是在别家手里成对（或成刻）了，此时见3万可以直 接开碰，改听单钓。（**中局之后少二八，必有对子手中拿**)
	- 5、**听牌后不要盲目抓打，也要随时换牌**。例如手上有一组123 万，摸进4万，如果判断4万下家有可能会吃，但1万是安全牌， 应该换打1万。（四连拆熟头)
	- 6、**遇到可以改听的机会，需要把握住**。例如，手牌1234万听14 万的双面钓，如果摸进5万，既可以继续听14万，也可以打1万改 听25万，如果25万的余量更好，应及时改听。
- 行牌技巧
	- 1、拿到起手牌后，先看是否可以搏十风。
	- 2、常规舍牌思路：先出风牌孤张，再打幺九二八孤张，再拆搭。
	- 3、三连坎的拆搭：前期打边留中，保留改良空间（例如135打1 留35的卡张搭子）；后期观察牌池，选择最佳听口。
	- 4、先拆边，后拆卡。（卡张搭子价值高于边张搭子)
	- 5、二三七八两面留；中盘无幺九，二三七八两面拆。23和78的 双面搭子，前期容易吃进（上家开局打幺九的概率较高），如果中后盘一直不见幺九，大概率已经成对、成刻，可以考虑拆搭。
	- 5、注意观察明断的牌张（封闭性原理）。断张的邻牌分布相对比较好判断，因为关联性减弱。例如场上7条没了，89条就无法成顺子，通常会被打出，或成对、成刻。
	- 6、头不吃。开局摸牌效率较高，尽量少吃牌，先吃边卡张。
	- 7、留杠牌。手中有杠牌，听牌之前原则上都不去开杠，先碰牌 留杠子。保留听牌之后杠开的机会。当然，提前开杠抢进度也是一种行牌思路。
	- 8、有财不定将。麻将常用口诀“一对定将”只适合无财的麻将， 手中有财神，不必留将牌，只有一对也可以开碰。
	- 9、碰牌要快，吃牌宜慢。能吃的牌不要急着报“吃”，先等一等看有没有人会碰牌。因为急着报“吃”，如果被人碰了，相当 于向三家暴露了自己需要的牌张。反之，需要碰牌时要快速报 “碰”，速度慢了下一家可能已经看到牌墙下一张牌是什么牌了。
	- 10、坐庄不做牌，做牌不坐庄。一方面，是要把握连庄的机会， 不要一味贪大被抢庄；另一方面，坐庄时上家很可能对你严防死守，很难通过吃牌来成牌。

## 猜牌与防守 ^4442ef84-9fc6-22f6
- 杭州麻将防守核心
	- 关键防守位置：庄家上家（默认需防守）
	- 防守前提：准确猜牌 + 识别安全牌
- 常用猜牌方法
	- 舍牌猜牌法：根据舍牌顺序判断手牌
		- 开局打1筒手里通常没有23筒。
		- 中盘以后从手牌打1筒，通常有23筒
		- 一直在抓打，多半已听牌
	- 基于牌型结构猜牌
		- 原理：胡牌需5搭牌，条/筒/万分6块区域，至少1块区域无需（类似四川麻将定缺）
		- 方法：根据对方打出牌张分布，推断其不需要的区域牌张
	- 基于牌背信息猜牌（线下适用）
		- 示例1：按顺序码牌，从右第三张打8万→推测最右两张为9万对
		- 示例2：4万与8万紧挨着→推测不需要4-8万间的万字牌
		- 应对建议：适当乱序码牌（新手注意：连续叙述牌勿断开摆放，避免漏看听口）
	- 基于对手行为猜牌
- 安全牌与危险牌识别（经验常识）
	- **核心要点：庄家拆搭时要防邻牌**
	- 口诀态度：不建议背诵（难以记住）
	- 自身拆搭技巧：借上下家东风
- 常规防守思路
	- 核心逻辑：杭州麻将结束不查听，防守较简单，坐在庄家上家跟打庄家不要的安全牌
	- 关键原则：
		- 宁可放弃听牌，也不能为庄家吃牌
		- 牢记“少输当赢”
		- 麻将打的是大概率
	- 手牌策略：
		- 庄家上家一般不要吃碰，保持手牌最多张数（增加选择余地，类似斗地主辅助农民保留牌型变化、扩大防守面积）
		- 有好牌时需敢于拼，勿过度保守
		- 庄家下家牌不好就尽量碰，让闲家队友多摸牌
